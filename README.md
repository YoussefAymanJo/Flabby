# Flabby

## Description
2d online game for the famous Flappy Bird game, where you try to collect a large number of points by staying alive and flying through obstacles.I want make this game ,it was simple one ,but a my my second game in godot with great develop,i followed tutorial in some parts and used free assets,i updated changes to the game , adding 3 health  for the player, i update scroing system, Player should try to get highest score every time and challenge himself.Also, diffucalty of game changes based on score ,getting more score increase diffuculty,finally,i added for SFX and music to give the game more entertaining, and created game UI. As I mentioned, it was my second game in godot.
## Game link 

https://youssef2008111.itch.io/flabby

## How to Play
To jump, click space
Try avoiding  pipes and passing through spaces to earn points,you have only 3 lifes,so take care of them.And try to beat you higesht score each time ,and watch out game speed increase by increasing score.
